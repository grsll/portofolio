Keahlian Teknis

Ringkasan teknologi dan spesialisasi yang saya gunakan dalam pengembangan sistem bisnis dan aplikasi mobile.

Arsitektur Odoo ERP

Odoo (v14 — v17): Pembuatan custom addons modul bisnis, model inheritance, automated actions.
XML Views & QWeb: Form, tree/list, kanban views, search filters, dan cetak laporan PDF dinamis.
Odoo ORM: Decorators (@api.depends, @api.constrains, @api.onchange), write/create overrides.
Modul Industri: Implementasi modul SIMRS rumah sakit, E-Tender, DMS, dan pergudangan.

Backend & Basis Data

Python 3: Pemrograman OOP, backend logic, data processing, dan integrasi API (PEP 8).
PostgreSQL: Desain skema relasional, indexing, foreign keys, dan optimasi query kueri kompleks.
Microsoft SQL Server: Integrasi database MSSQL dengan Next.js / Prisma ORM via Docker.
API & Middleware: REST API, JSON-RPC, XML-RPC, autentikasi token JWT, dan validasi data.

Mobile & Web Frontend

Flutter & Dart: Aplikasi mobile cross-platform (Android/iOS) dengan performa tinggi.
State Management: Clean Architecture, Riverpod, dan Provider untuk manajemen alur data.
Penyimpanan Lokal: SQLite terenkripsi dan cache offline-first.
Next.js & Web: Next.js 16 (App Router), TypeScript, Tailwind CSS, HTML5, Owl JS.

Tools & Lingkungan

Docker: Containerization Odoo, PostgreSQL, dan MSSQL dengan Docker Compose.
Linux / Ubuntu: Navigasi server CLI harian, permission, dan manajemen service systemd.
Git & GitHub: Version control, branch management, dan collaborative workflows.
Debugging: Postman, Insomnia, log analysis, dan database profiling.
