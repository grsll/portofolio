# Design System Master File — YOGA.DEV

**Project:** Yoga Setyawan Portfolio (YOGA.DEV)  
**Style:** Minimalist Monochrome (Black & White) Software Engineer Portfolio  
**Focus:** Odoo ERP Engineering, Python Backend, Flutter Mobile  

---

## 1. Global Color Tokens (Black & White)

| Token | Hex / Value | Usage |
|---|---|---|
| `--color-bg` | `#FFFFFF` | Background putih bersih |
| `--color-surface` | `#F9F9F9` | Surface panel lembut untuk input / cards |
| `--color-text` | `#111111` | Teks judul dan heading utama (deep black) |
| `--color-text-secondary` | `#555555` | Teks paragraf tubuh dan deskripsi |
| `--color-text-muted` | `#888888` | Teks metadata, tanggal, dan label sekunder |
| `--color-border` | `#E5E5E5` | Garis batas dan pemisah |
| `--color-border-subtle` | `#EEEEEE` | Garis batas elemen internal |
| `--color-accent` | `#111111` | Aksen hitam tegas |
| `--color-accent-subtle` | `#F0F0F0` | Latar belakang pill status dan badge abu-abu muda |

---

## 2. Typography

- **Primary Sans Font:** `IBM Plex Sans` (400, 500, 600, 700)
- **Technical Monospace Font:** `JetBrains Mono` (400, 500)

---

## 3. Design Character

- Sederhana, bersih, berorientasi teks, super cepat dimuat, tanpa foto proyek yang membebani tampilan.
