Unduh File PDF

Nama lengkap saya Yoga Setyawan Purwanto. Saat ini saya berfokus sebagai Odoo Developer di PT Karyatama Solusindo di Jakarta, dengan spesialisasi pengembangan modul kustom, penyesuaian alur kerja operasional, dan integrasi sistem enterprise.

Perjalanan saya di dunia pemrograman berakar dari rasa ingin tahu yang mendalam dan komitmen belajar terarah. Bermula dari penguasaan dasar-dasar web dan algoritma komputasi, saya kemudian mendalami bahasa Python, basis data PostgreSQL, dan kontainerisasi Docker, hingga akhirnya memilih spesialisasi pada ekosistem Odoo ERP.

Bagi saya, sistem ERP yang sukses bukan dinilai dari seberapa rumit tampilan antarmukanya, melainkan dari stabilitas data, kemudahan pemeliharaan (maintainability), dan kemampuannya menyelesaikan hambatan nyata operasional bisnis. Karena itulah, saya selalu berpegang pada prinsip penulisan kode modular, pemanfaatan inheritance model secara tepat, serta struktur kueri yang efisien.

Di samping ekosistem Odoo, saya juga aktif mengembangkan aplikasi mobile berbasis Flutter. Kemampuan ini memungkinkan saya menjembatani kebutuhan sistem core ERP di backoffice dengan kebutuhan mobilitas operasional pengguna di lapangan secara harmonis.
